# PyCharm Shortcuts

## Navigation

- [Desktop](#desktop)
- [Surface Pro](#surface-pro)

This reference tracks separate custom PyCharm keymaps for the desktop and
Surface Pro. Update the matching section whenever a shortcut is added or
remapped.

## Desktop

These are the current desktop keybindings.

### Switch Tools

| Shortcut | Action |
|---|---|
| `Esc` | Return to Editor |
| `Alt + A` | Open AI Chat |
| `Alt + T` | Open Terminal |
| `Alt + Shift + Q` | Select All in Terminal |

### Work With Code

| Shortcut | Action |
|---|---|
| `Ctrl + Alt + L` | Reformat Code |
| `Ctrl + Shift + A` | Find Action |
| `Shift`, `Shift` | Search Everywhere |
| `Shift + F6` | Rename |

### Navigate Files

| Shortcut | Action |
|---|---|
| `Alt + Right` / `Alt + Left` | Cycle through open editor tabs |
| `Ctrl + Tab` | Open the Switcher; hold `Ctrl` and press `Tab` to move through open files |
| `Ctrl + Shift + N` | Search for a project file by name; press `Enter` to open it |
| `Ctrl + E` | Open Recent Files |

## Verify a Keybinding

Open **Settings > Keymap** and search for the action name. After assigning the
shortcut, test it on the intended device before marking it as configured in
this document.
