# PyCharm Shortcuts

## Navigation

- [Desktop](#desktop)
- [Surface Pro](#surface-pro)

This reference tracks separate custom PyCharm keymaps for the desktop and
Surface Pro. Update the matching section whenever a shortcut is added or
remapped.

## Desktop

These are the current desktop keybindings.

### Switch Tools

| Shortcut | Action | Notes |
|---|---|---|
| `Esc` | Return to Editor | Moves focus from a tool window back to the editor |
| `Alt + A` | Open AI Chat | Uses the custom desktop keymap |
| `Alt + T` | Open Terminal | Replaces the default `Alt + F12` binding |
| `Alt + Shift + Q` | Select All in Terminal | Terminal focus required |

### Terminal Sessions

| Shortcut | Action | Notes |
|---|---|---|
| `Alt + Right` / `Alt + Left` | Cycle through open terminal sessions | Terminal focus required |
| `Alt + Down` | Show all open terminal sessions | Useful when more than two sessions are open |
| `Ctrl + Shift + T` | Open a new terminal session | The new session opens in a separate terminal tab |

### Work With Code

| Shortcut | Action | Notes |
|---|---|---|
| `Ctrl + Alt + L` | Reformat Code | Reformats the current file or selected code |
| `Ctrl + Shift + A` | Find Action | Searches PyCharm actions and settings |
| `Shift`, `Shift` | Search Everywhere | Press `Shift` twice quickly |
| `Shift + F6` | Rename | Safely renames a selected code symbol or file |

### Navigate Files

| Shortcut | Action | Notes |
|---|---|---|
| `Alt + Right` / `Alt + Left` | Cycle through open editor tabs | Editor focus required |
| `Ctrl + Tab` | Open the Switcher | Hold `Ctrl` and press `Tab` to move through open files |
| `Ctrl + Shift + N` | Search for a project file by name | Press `Enter` to open the selected file |
| `Ctrl + E` | Open Recent Files | Includes recently used files that are not open |

## Verify a Keybinding

Open **Settings > Keymap** and search for the action name. After assigning the
shortcut, test it on the intended device before marking it as configured in
this document.
